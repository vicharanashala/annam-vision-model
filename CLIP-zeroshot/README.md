# CLIP Zero-Shot Plant Disease Classification

This repository evaluates **CLIP zero-shot learning** for plant leaf disease
classification using **prompt ensembling**.

## Model Used
- **CLIP ViT-L/14**
- Zero-shot inference (no training or fine-tuning)

## Objective
- Test CLIP's ability to classify plant diseases without task-specific training
- Evaluate generalization using text-image similarity

## Method
- Prompt ensembling for class descriptions
- Direct zero-shot evaluation on benchmark images

## Note
- ❌ No fine-tuning performed
- Model is used strictly in zero-shot mode
