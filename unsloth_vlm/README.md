# Vision Reinforcement Learning with Unsloth Qwen3-VL

This repository contains experiments using **Unsloth Vision Reinforcement Learning for VLMs** as described here:  
https://docs.unsloth.ai/new/vision-reinforcement-learning-vlm-rl

## Model Used
- **unsloth/Qwen3-VL-8B-Instruct-unsloth-bnb-4bit**

## Objective
- Perform plant leaf disease detection and classification
- Evaluate performance with and without fine-tuning

## Training Details
- Fine-tuning performed using Unsloth
- `max_sequence_length = 1024`
- Benchmark dataset used for evaluation
