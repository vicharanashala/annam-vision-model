# Plant Leaf Disease Detection using Ollama

This project experiments with **plant leaf disease detection** using **Ollama** and vision-language models.

## Models Used
- **Qwen (Vision model)**
- **LLaVA**

These models are accessed locally using **Ollama** for inference only.

## Purpose
- Test whether general-purpose VLMs can identify plant type and leaf diseases
- Evaluate zero-shot performance without training

## Important Note
- ❌ **Fine-tuning is NOT supported in Ollama**
- Models like Qwen and LLaVA are used **as-is** (pretrained only)
- Accuracy depends entirely on the model’s general knowledge

## Status
This is an experimental setup for testing and comparison only.
