# Plant Leaf Disease Classification using EfficientNet-B4

This repository contains experiments using a **CNN-based image classification
model** for plant leaf disease detection.

## Model Used
- **EfficientNet-B4**

## Training Details
- Model fine-tuned on benchmark dataset
- Two training configurations tested:
  - 20 epochs
  - 50 epochs

## Objective
- Evaluate performance on benchmark dataset
- Test generalization on real-world field images

## Model Selection
- Based on benchmark performance, the model trained for **50 epochs**
was selected for further use
